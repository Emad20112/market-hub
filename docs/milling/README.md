# دليل المطحنة — من أين يبدأ أي مطوّر أو أيجنت

> هذا المجلد هو **المصدر الوحيد** لخطة وحدة المطحنة. أي خطة سابقة خارج هذا المجلد مُلغاة.

## القراءة بالترتيب (إلزامية)

1. **[`00_خطة_التبسيط_المعتمدة.md`](00_خطة_التبسيط_المعتمدة.md)** — العقد النهائي.
   الفكرة الجوهرية، القرارات المحسومة (ق1–ق10)، نموذج `custody_ledger`، الواجهة، القواعد الذهبية.
   *لا تبدأ أي عمل قبل قراءته وفهمه.*

2. **[`01_التحليل_المعمق_وحذف_التعقيد.md`](01_التحليل_المعمق_وحذف_التعقيد.md)** — لماذا نحذف كل شيء نحذفه.
   تشريح فعلي للجداول والدوال والشاشات والأوضاع الحالية بأسماء الملفات.

3. **[`02_خطة_الإصلاح_والتنفيذ.md`](02_خطة_الإصلاح_والتنفيذ.md)** — كيف ننفّذ.
   خطوات 0→8 بالترتيب، شرط خروج لكل خطوة، 12 حالة اختبار، checklist التسليم.

4. **[`03_دليل_التشغيل_لصاحب_المطحنة.md`](03_دليل_التشغيل_لصاحب_المطحنة.md)** — دليل التشغيل بلغة صاحب المطحنة.
   الشاشات، دورة اليوم، مصفوفة الأمان، التوزيع النسبي للتكلفة، وأجوبة كل ما يخطر في باله.
   *يُحدّث عند أي تغيير يؤثر على طريقة الاستخدام.*

## أول إجراء عملي دائماً

الخطوة 0 في `02`: `npm run lint -- --fix` ثم `npm run lint` ثم `npm run build` — التطبيق معطّل البناء (114 خطأ) حتى تُنجز هذه الخطوة.

## قواعد الطريق السريع

- **مصدر واحد لكل بيانات** — لا شيء يُدخل في مكانين.
- **الرصيد مشتق لا مخزَّن** — `sum(bags_in − bags_out)`.
- **لا فاقد، لا أوزان عبوات، لا أوامر، لا صوامع** — ق2/ق3.
- **كتابة عبر RPC فقط** على الجداول المالية (R-23).
- **الملفات القديمة مُلغاة:** `تحليل وتبسيط المطحنة.md` (فهرس/أرشيف فقط)، `MILLING_SYSTEM_IMPROVEMENT_PLAN.md`، `plan,mill.md`، `معلومات عن المطحنه.md` (سياق أعمال فقط)، `txt.txt` (محضر القرارات الأصلي).
